# Code and data availability

Code, computational environment information, figures, and aggregate or derived tables needed to audit and reproduce the reported results are publicly available at https://github.com/RafaelBotan/breast-prognostic-signature-robustness-2026. No individual patient data are redistributed. Source expression and clinical data should be obtained directly from GEO, GDC, cBioPortal, or EGA using the cohort accessions listed in the manuscript and this repository.
