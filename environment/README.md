# Computational environment

The final revision build used R 4.5.3. `sessionInfo.txt` records the operating system, locale, attached packages, loaded namespaces, and exact installed-package versions from the verified run.

The repository does not claim a fully locked `renv` environment because no `renv.lock` was created for the submitted analysis. Reproduction should therefore start from the recorded R and package versions rather than silently installing current versions.
